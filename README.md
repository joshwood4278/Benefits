# Benefits
VA Benefits Navigation

The education page includes links to all 50 state veterans agencies and a
school-cost scenario estimator. State programs vary; confirm current eligibility
and benefit amounts with the linked state agency or school. The financial
dashboard estimates projected 2027 VA disability compensation using marital
status and dependent ages entered in the profile. The 2027 rates are projections,
not official VA rates, and the estimate is not an eligibility determination.
