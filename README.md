# Benefits
VA Benefits Navigation

The State Benefits page shows the official veterans agency and currently
catalogued programs for the state selected in the profile, with separate Veteran
and Dependent views. State programs vary; confirm current eligibility and
benefit amounts with the linked state agency or school. The profile also records
the selected BRS or High-3 retirement system. The financial dashboard estimates
projected 2027 VA disability compensation using marital status and dependent
ages entered in the profile. The 2027 rates are projections, not official VA
rates, and the estimate is not an eligibility determination.
